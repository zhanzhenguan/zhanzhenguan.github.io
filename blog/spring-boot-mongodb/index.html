这篇是 Spring Boot 系列第六部分，整合 MongoDB 文档数据库：先理解文档模型与关系型表结构的差异，再通过 spring-boot-starter-data-mongodb 完成接入，掌握 MongoTemplate 与 MongoRepository 两种数据访问方式及常用注解。代码为通用示例，连接信息用占位符。

一、MongoDB 基本概念

与 MySQL、Oracle 这类关系型数据库不同，MongoDB 是文档数据库：数据存储在灵活的、类 JSON 的文档（BSON）中，同一集合内不同文档的字段可以不同，数据结构可随时间演变。文档模型能直接映射到应用代码中的对象，处理起来更直观。

MongoDB 以分布式为核心设计，高可用、横向扩展与地理分布是内置能力，同时开源免费。

二、整合步骤

2.1 添加依赖

引入 Spring Data MongoDB 启动器：

<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-data-mongodb</artifactId>
</dependency>

2.2 配置 application.yml

通过 spring.data.mongodb 前缀配置连接；uri 方式可一次性携带地址、库名与凭证：

spring:
  data:
    mongodb:
      uri: mongodb://demo:${MONGO_PASSWORD:change-me}@localhost:27017/demo?authSource=admin

也可以拆开配置主机、端口、数据库、用户名与密码。

2.3 实体类

用注解把 Java 类映射为 MongoDB 文档：

@Document(collection = "user_entity")
@Data
public class UserEntity {

    @Id
    private String id;

    @Field("user_name")
    private String name;

    private Integer age;

    private String address;
}

2.4 MongoTemplate 增删改查

注入 MongoTemplate 即可直接操作文档。插入后 MongoDB 会自动创建数据库与集合；_id 为主键，_class 字段由 Spring Data 自动写入，值为实体类的全限定包名 + 类名。

@Service
public class UserService {

    private final MongoTemplate mongoTemplate;

    public UserService(MongoTemplate mongoTemplate) {
        this.mongoTemplate = mongoTemplate;
    }

    // 插入
    public void save(UserEntity user) {
        mongoTemplate.save(user);
    }

    // 按主键查询
    public UserEntity findById(String id) {
        return mongoTemplate.findById(id, UserEntity.class);
    }

    // 条件查询
    public List<UserEntity> findByName(String name) {
        Query query = new Query(Criteria.where("user_name").is(name));
        return mongoTemplate.find(query, UserEntity.class);
    }

    // 更新
    public void updateAddress(String id, String address) {
        Query query = new Query(Criteria.where("_id").is(id));
        Update update = new Update().set("address", address);
        mongoTemplate.updateFirst(query, update, UserEntity.class);
    }

    // 删除
    public void delete(String id) {
        Query query = new Query(Criteria.where("_id").is(id));
        mongoTemplate.remove(query, UserEntity.class);
    }
}

可用 Navicat 等可视化工具连接 MongoDB 查看集合与文档。

三、MongoRepository 接口

3.1 基本概念

MongoRepository 是 Spring Data MongoDB 提供的数据访问接口，泛型参数为：

  • T：实体类类型；
  • ID：主键类型。

它继承自 CrudRepository 与 PagingAndSortingRepository，具备基础 CRUD、分页与排序能力，并提供 MongoDB 特有方法。

3.2 优势

  • 无需写实现类：接口由 Spring Data 基础设施在运行时生成代理实现；
  • 自动生成查询逻辑：按方法名约定推导查询条件；
  • 支持复杂查询、分页、排序。

3.3 使用示例

定义实体后，编写 Repository 接口：

public interface UserRepository extends MongoRepository<UserEntity, String> {

    List<UserEntity> findByName(String name);

    Page<UserEntity> findByAgeGreaterThan(Integer age, Pageable pageable);
}

直接注入使用：

@Service
public class UserRepositoryService {

    private final UserRepository userRepository;

    public UserRepositoryService(UserRepository userRepository) {
        this.userRepository = userRepository;
    }

    public List<UserEntity> query(String name) {
        return userRepository.findByName(name);
    }
}

四、SimpleMongoRepository 与代理机制

SimpleMongoRepository 是 Spring Data MongoDB 提供的 默认 Repository 实现类，封装了常见 CRUD 操作，开发者不必编写底层 MongoDB 访问代码。

当你定义一个继承 MongoRepository 的接口时，Spring Data 的 Repository 基础设施会为其创建代理对象，而不是把接口直接变成普通对象；代理内部还可能包含查询方法解析、事务等拦截逻辑，最终委托给 SimpleMongoRepository 完成实际数据访问。

五、常用映射注解

注解 作用
@Document 将 Java 类映射为 MongoDB 文档，类似 JPA 的 @Entity；可通过 collection/value 指定集合名，不指定时默认把类名转为小写；db 指定库名（一般用全局配置）；language 指定文本搜索默认语言；collation 指定排序规则
@Id 标识主键字段，映射到 MongoDB 的 _id
@Field 自定义文档字段名映射
@Indexed 为字段创建索引
@CompoundIndex 创建复合索引，标注在类级别
@Transient 标识不需要持久化的字段
@DBRef 引用其他集合的文档

@Document 是持久化实体的基础注解：完成实体映射、集合指定，配合 Spring Data 实现对象文档映射，以注解驱动减少配置代码。

六、小结

  • MongoDB 是文档数据库，schema 灵活、分布式能力内置，文档直接映射应用对象；
  • 引入 spring-boot-starter-data-mongodb，在 spring.data.mongodb 下配置连接即可接入；
  • 两种访问方式：MongoTemplate 手写条件与操作，MongoRepository 靠接口方法名推导查询，实现类由 Spring Data 代理生成，默认实现为 SimpleMongoRepository；
  • 持久化实体用 @Document 映射集合，@Id 映射主键，配合 @Field、@Indexed、@DBRef 等注解完成字段、索引与关联映射。
