你好，世界 —— 我的第一篇博客

2026/11/25 #随笔#入门

欢迎来到我的博客！这是第一篇示例文章。以后新增文章，只要在 src/content/blog/ 目录下新建一个 .md 文件，填好顶部的 frontmatter 即可。

怎么写新文章

  1. 在 src/content/blog/ 下新建 我的文章标题.md
  2. 按下面的格式填写头部信息：
---
title: 文章标题
description: 一句话摘要，会显示在列表页和浏览器描述里
pubDate: 2026-11-25
tags: [标签一, 标签二]
draft: false
---
  1. 正文用 Markdown 书写，支持标题、列表、代码块、图片等。
  2. 想先存草稿不对外展示，把 draft 设为 true。

支持的 Markdown 语法

  • 行内代码：npm run dev
  • 代码块：
npm install
npm run dev
  • 加粗、斜体、链接
  • 无序列表：
    • 条目一
    • 条目二

引用块也可以正常渲染。

写完保存后，本地 dev 服务器会自动热更新，刷新页面就能看到。
