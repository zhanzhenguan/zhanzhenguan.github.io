简介

你好，我是一名全栈开发工程师。主要从事全栈及企业级业务系统开发，参与过 Agent 开发、SaaS 平台、ERP、WMS、 微信小程序、数据中台、即时通讯客服和虚拟仿真平台等。

具备扎实的后端工程与数据存储能力：精通 MySQL 表结构设计与 SQL 调优，熟练使用 Redis（含分布式锁）、 RabbitMQ / RocketMQ 等消息队列，以及 XXL-Job 定时任务调度；能够独立完成第三方 OpenAPI 对接， 处理签名验签、超时控制、请求重放与数据一致性等线上治理问题。

在交易类系统设计上，覆盖下单、回调、查询、对账匹配、异常补偿、失败重试、幂等控制与最终一致性等完整链路； 对精度计算、并发冲突、重复提交、状态机混乱等高风险场景有较强敏感度，习惯从方案设计到线上排查全链路把控。

日常关注高并发、高可用、高性能场景下的并发控制、分布式锁、异步消息、定时补偿与数据一致性方案， 注重系统的稳定性、可追踪与可恢复。

这个博客用来沉淀技术笔记、项目实践与踩坑总结，欢迎交流。
